Addon features

The systems already built into the project.

Quest browser

Quest giver, pickup location, objective, completion text, faction, minimum level and prerequisite chains.

Maps & pins

Custom maps with clickable markers and per-quest coordinates calibrated against the displayed map.

Boss browser

Dungeon boss lists with visual presentation and loot attached to each encounter.

Item tooltips

Boss loot and quest rewards can use in-game item IDs so players can inspect real item stats.

Dungeon artwork

Custom dungeon entrance art, quest-giver portraits and a WoW-styled interface rather than a plain database screen.

Forever focused

The project is being built around WoW Forever content and the dungeon information players actually need in-game.
